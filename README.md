# Claude-Mods

- [`toolkit-marketplace/`](toolkit-marketplace/) — **Toolkit**, one Claude Code mod with seven features (voice prompt cleaner, Helper Desk agent monitor, Keep Warm, Project Map + Chat Meter, Plan Usage, Skill Helper, Auto Model). See its [README](toolkit-marketplace/plugins/toolkit/README.md) and [CAPABILITIES.md](toolkit-marketplace/CAPABILITIES.md).

Install on Windows (in a Claude Code terminal session):

```
/plugin marketplace add C:\path\to\Claude-Mods\toolkit-marketplace
/plugin install toolkit@toolkit-local
/reload-plugins
```
